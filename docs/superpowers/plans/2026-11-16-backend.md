# NexSaúde IA — Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** API REST em Spring Boot para o MVP do NexSaúde IA: login por perfil, pacientes/consentimento, triagem assistida por IA, leitos/internação, prescrição com verificação de interação por IA, prontuário e auditoria imutável.

**Architecture:** Monólito Spring Boot com pacotes por módulo (`auth`, `paciente`, `triagem`, `leito`, `prescricao`, `auditoria`, `ia`, `common`), PostgreSQL com Flyway e IA atrás da interface `AssistenteClinicoIA`, com duas implementações (Claude e simulada). O contrato da API (DTOs + controllers + Swagger) é publicado cedo (Task 4) e implementado módulo a módulo sem mudar.

**Tech Stack:** Java 21, Spring Boot 3.x (última 3.x), Maven Wrapper, Spring Web/Data JPA/Security/Validation, Flyway, PostgreSQL 16, springdoc-openapi, jjwt, `com.anthropic:anthropic-java:3.3.0`, JUnit 5, Testcontainers, MockMvc.

**Spec:** `docs/superpowers/specs/2026-11-16-backend-design.md` (requisitos originais: `docs/requisitos/NexSaudeIA_ERS.pdf`)

## Global Constraints

- Código em `backend/`, pacote raiz `br.ucsal.nexsaude`, Java 21, build com `./mvnw` (sem Maven global).
- Pacotes por módulo. Cada módulo tem `XController`, `XService`, `XRepository`, entidades e `dto/` (DTOs como `record`). Nunca expor entidade JPA no controller.
- Prefixo de rotas `/api`. Erros em `ProblemDetail` (RFC 7807): validação → 400, regra de negócio → 422, sem permissão → 403, não encontrado → 404.
- Esquema só por Flyway (`spring.jpa.hibernate.ddl-auto=validate`). Uma migração por task que muda o banco, numeradas em sequência (`V1__`, `V2__`…). O seed fica em `db/seed/V99__seed_dev.sql`, carregado só no perfil `dev`.
- CORS liberado para `http://localhost:5173`.
- Perfis de usuário: `ADMIN, ENFERMEIRO, MEDICO, GESTOR_LEITOS, AUDITOR`.
- Cores Manchester: `VERMELHO, LARANJA, AMARELO, VERDE, AZUL` (prioridade nessa ordem).
- IA: `nexsaude.ia.modo` ∈ {`simulada`, `claude`}, padrão `simulada`. Modelo padrão `claude-opus-5-5`, configurável em `nexsaude.ia.modelo`. Timeout de 10 s. Nunca enviar nome nem CPF à IA.
- Toda ação clínica de escrita e toda chamada à IA gera um `LogAuditoria`. A tabela não aceita UPDATE/DELETE.
- Mensagens de erro e textos voltados ao usuário em português.
- Testes de integração usam Testcontainers (PostgreSQL 16) e uma classe base comum `IntegrationTest`.

## Review Focus

1. **Duas triagens/reclassificações quase simultâneas no mesmo atendimento**: as duas viram linhas novas e a fila usa a mais recente por `dataHora`. Nada é sobrescrito. Teste na Task 7.
2. **Alocar o mesmo leito LIVRE para dois pacientes**: a segunda alocação recebe 422 e não gera dois ocupantes (lock otimista `@Version` em `Leito`). Teste na Task 8.
3. **CPF duplicado ou com máscara** (`123.456.789-09` vs `12345678909`): o CPF é normalizado para só dígitos e validado pelo dígito verificador, e o duplicado devolve 422. Teste na Task 5.
4. **A IA devolve algo inválido (cor fora do enum, JSON quebrado, recusa, timeout)**: é tratado como "IA indisponível", fica registrado no log e o fluxo manual continua. Nunca devolve 500. Teste na Task 6.
5. **Token JWT expirado ou de usuário desativado**: devolve 401, nunca 500 nem acesso. Teste na Task 3.

- `IAConfig` cria o bean `AssistenteClinicoIA` conforme `nexsaude.ia.modo`. O `ClaudeIA` usa `AnthropicOkHttpClient.builder().fromEnv().timeout(Duration.ofSeconds(10))` e saída estruturada com `MessageCreateParams.builder().model(modelo).maxTokens(2000L).outputConfig(RespostaTriagemClaude.class)` (record interno com os campos do resultado). O system prompt vem de `prompts/triagem-v1.txt`. Antes de ler o conteúdo, ele checa `stopReason`: `refusal`, `max_tokens`, cor fora do enum ou exceção do SDK viram `IAIndisponivelException`.

  - AMARELO: `temperatura >= 38` ou `fc > 100`
  - VERDE: sintomas não vazios
  - AZUL: caso contrário

  A confiança é fixa em 0,7. Pares GRAVE: varfarina+AAS e sildenafila+nitroglicerina. Par MODERADA: enalapril+espironolactona. A comparação ignora caixa e acentos.
